# Telegram Bot Auto-Responder with Mini App

Telegram бот-автоответчик с веб-интерфейсом для управления настройками.

## Возможности

- Автоматические ответы на сообщения
- Система правил (точные и частичные совпадения)
- ИИ-генерация ответов через g4f (бесплатный GPT)
- Веб-интерфейс (Mini App) для управления
- Уведомления владельцу о входящих сообщениях
- Фильтрация: все / незнакомцы / белый список / чёрный список

## Установка

### 1. Создание бота

1. Откройте @BotFather в Telegram
2. Создайте нового бота: `/newbot`
3. Сохраните токен
4. Создайте Mini App: `/newapp`
5. Укажите URL GitHub Pages (после деплоя фронтенда)

### 2. Получение OWNER_ID

1. Откройте @userinfobot в Telegram
2. Отправьте любое сообщение
3. Сохраните свой ID

### 3. Деплой бота на Render

1. Загрузите папку `bot/` в GitHub репозиторий
2. На [Render](https://render.com) создайте новый Web Service
3. Подключите GitHub репозиторий
4. Добавьте переменные окружения:
   - `BOT_TOKEN` = ваш токен
   - `OWNER_ID` = ваш Telegram ID
5. Build Command: `pip install -r requirements.txt`
6. Start Command: `sh start.sh`
7. Порт: `10000`

### 4. Деплой Mini App на GitHub Pages

1. Загрузите папку `miniapp/` в GitHub репозиторий
2. В `script.js` замените `YOUR_BOT_USERNAME` на имя вашего бота
3. Включите GitHub Pages в настройках репозитория (Settings → Pages → Source: main branch)
4. Скопируйте URL (например, `https://username.github.io/repo-name/`)
5. В @BotFather создайте Mini App с этим URL

### 5. Настройка URL Mini App

В файле `bot.py` замените дефолтный URL на ваш:

```python
async def get_webapp_url() -> str:
    url = db.get_setting("webapp_url")
    if url:
        return url
    return "https://yourusername.github.io/your-repo/"
```

Или установите через Mini App в поле "URL Mini App".

## Команды бота

- `/start` — Приветствие и кнопка настроек
- `/settings` — Открыть Mini App
- `/help` — Справка

## Настройка через Mini App

1. **Главная** — Включение/выключение автоответчика, уведомлений, имя владельца
2. **Режим ответа** — Выбор фильтра (все / незнакомцы / белый список / чёрный список)
3. **Правила** — Добавление/удаление правил автоматических ответов
4. **Настройки ИИ** — Промпт для ИИ, тестирование

## Как это работает

1. Бот получает сообщение
2. Проверяет, включён ли автоответчик
3. Применяет фильтр (все/незнакомцы/списки)
4. Ищет совпадение в правилах (сначала точные, потом частичные)
5. Если правило найдено — отправляет готовый ответ
6. Если нет — генерирует ответ через ИИ (g4f)
7. Отправляет уведомление владельцу

## Технологии

- g4f — Бесплатный доступ к GPT
- SQLite — Хранение настроек

- HTML/CSS/JS — Mini App интерфейс
